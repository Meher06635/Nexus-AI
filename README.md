AI Desktop Agent – Nexus AI

An AI-powered autonomous desktop assistant capable of performing real-time computer tasks using voice and text commands. The system uses LLM-based reasoning and automation tools to execute workflows such as browser control, WhatsApp messaging, web search, note creation, and desktop automation.

Features
Voice-controlled AI assistant
Browser automation using Playwright
WhatsApp message automation
Intelligent task planning using LLMs
Desktop automation with PyAutoGUI
Web search and application control
Note creation and file handling
AI-powered workflow execution
Modern React-based UI
